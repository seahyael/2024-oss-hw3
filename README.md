# OSS HW 3 — 도서관리 UI와 JSON 데이터 실습

도서관리 화면을 구성하고 JSON 데이터를 다루는 방법을 연습한 웹 과제입니다.

## 실습 내용

### 도서관리 화면

- 책 목록과 책 상세 화면 구성
- 도서 추가 및 수정 폼 작성
- 필수 입력값 검사와 삭제 확인창 구현
- 샘플 도서 정보를 사용한 화면 구성

도서관리 화면은 UI와 입력 동작을 연습하기 위한 프로토타입입니다. 현재 코드에서는 도서 정보가 서버나 데이터 파일에 저장되지는 않습니다.

### 학생 데이터 관리

- JSON Server에서 학생 목록 조회
- 학생 이름과 나이 추가
- 선택한 학생 정보 수정 및 삭제
- XMLHttpRequest를 이용한 AJAX 요청

### JSON 기초

- `JSON.stringify()`와 `JSON.parse()` 사용 연습
- JavaScript 객체 및 클래스 상속 예제

## 기술

- HTML
- CSS
- JavaScript
- Bootstrap
- jQuery
- JSON Server
